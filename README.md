## Project Overview
This project is a machine learning project focused on housing price prediction. The main purpose of the project is to analyze housing data and train a machine learning model that can predict the approximate price of an apartment based on its characteristics. 
The dataset includes features such as city, number of 
rooms, area, floor, house type, year of construction, and price.

The project follows a standard machine learning workflow: data loading, data analysis, preprocessing, model training, evaluation, and prediction. The final result of the project is a working Python program that trains several machine learning models, compares their performance, and shows a sample prediction.
This project is a machine learning project for predicting housing prices based on apartment features such as city, number of rooms, area, floor, house type, and year of construction.
The goal of this project is to build a machine learning model that predicts housing prices using a housing dataset.
